# AT-Project-2-EyeTracking

SCP CONTAINMENT BREACH EYE TRACKING EDITION
------------------------------------------------------------------------------------------------------------------------------------------------------
This the my course work for the Advanced Technologies Module at UWE Bristol

This readme will cover both a brief summary of the project along with references to all used external assets, software and videos used to create the project

------------------------------------------------------------------------------------------------------------------------------------------------------
BREIF
------------------------------------------------------------------------------------------------------------------------------------------------------
This short game is a custom re-imagined version of SCP containment breach with the primary change being a majority of interactions and engagements
now using eye tracking as the input.

Key Features and Changes

-Environmental Interactions
    
    Players interact with buttons and objects using gaze-based positioning

-Items and Pickups
    
    Item collection is controlled using eye position

-Inventory System
    
    Navigation, Selection, Use and Dropping within the inventory is managed using the players eye position.

-SCP interactions
    
    SCP behaviour is respondent to where the player is looking.

IMPLEMENTATION
------------------------------------------------------------------------------------------------------------------------------------------------------
-Unity (Game Engine)

HOW TO RUN THE PROJECT
------------------------------------------------------------------------------------------------------------------------------------------------------
[REQUIREMENTS]
Unity 6 (6000.1.9F1)
Beam Eye Tracker Software
Webcam

[IN-ENGINE]
1. Clone Repo
2. Install Beam Eye Tracker
3. Download the Beam Eye Tracker Unity SDK from the documentation website
2. Launch project in Unity, add the SDK to the package list
3. Run the project through main menu or level and the eye tracker will automatically enable

[BUILD]
1. Install Beam Eye Tracking via Steam or Website
(Note if installed from website you need to restart your computer for Unity to detect the input)
2. Run calibration on Beam Eye Tracker for an accurate experience
3. Run the project exe
4. Press play on main menu
5. Beam Eye Tracker will be automatically when entering the main level
6. Play :)
